# Working Notes

## User context
- Working professional, minimal time. Reviews trades ~bi-weekly → lessons & routines must
  fit a low-frequency cadence. Bias toward swing/position, not intraday.
- Wants principles compressed **one lesson per video**, then applied to own trading,
  then codified for AI + MCP (Notion + TradingView already configured in `.cursor/mcp.json`).

## Teaching preferences
- **Reporting: extremely concise. Sacrifice grammar for concision.** Applies to chat replies.
- **Visuals > text.** User wants to *see & remember*, not read. Mermaid flowcharts = too weak.
  For chart concepts (trading), draw the real thing: inline **SVG candlestick / price-wave
  sketches** annotated with HH/HL, LH/LL, ranges, timeframe context. A structure lesson should
  *look like a chart*, not a box-and-arrow diagram. Keep prose minimal, let the picture carry it.
- Each lesson: max ~1 short paragraph per idea, rest is visual + labels.

## Cadence idea (tie to mission)
- Bi-weekly ritual: run the 4-second watchlist scan → shortlist strong uptrends →
  write entry/invalidation/exit → set triggers. This is the real-world loop each lesson feeds.
